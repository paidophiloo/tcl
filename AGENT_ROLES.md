# Agent Roles — divisão recomendada de trabalho

Estas funções podem ser executadas por subagentes quando o ambiente oferecer suporte, ou usadas como checklists pelo agente principal.

## Product Guardian

- protege visão, escopo e não genericidade;
- compara implementação com `PRODUCT_BIBLE.md`;
- rejeita features bonitas sem impacto real.

## Match UX Agent

- hierarquia da tela;
- progressive disclosure;
- área técnica;
- bottom sheet;
- atalhos;
- legibilidade e feedback.

## Field Renderer Agent

- câmera;
- perspectiva;
- gramado;
- jogadores;
- sombras;
- bola;
- performance;
- resize.

## Tactical Simulation Agent

- targets de posição;
- formação com e sem bola;
- largura, linha e pressão;
- transições;
- comandos pendentes e aplicados.

## Data & Explainability Agent

- eventos;
- timeline;
- estatísticas coerentes;
- razões causais;
- assistente técnico.

## QA Agent

- execução local;
- console;
- controles;
- atalhos;
- screenshots;
- regressões;
- critérios de aceite.

## Regra

Não paralelizar arquivos conflitantes sem plano. O agente principal integra e valida o resultado completo.
